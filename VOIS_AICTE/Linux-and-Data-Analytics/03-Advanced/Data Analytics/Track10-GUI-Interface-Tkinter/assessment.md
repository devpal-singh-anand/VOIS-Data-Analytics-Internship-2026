# VOIS Assessment — Getting Started with Tkinter GUI Interface

## Questions and Answers

### 1. For user Entry data, which widget we use in tkinter?

* Text
* Entry
* Both of above
* None of above

**Answer:** Both of above

---

### 2. What is necessary for creating a window screen using Tkinter Python?

* Call `tk()` function
* Create Button
* To define a geometry
* All of the above

**Answer:** Call `tk()` function

---

### 3. To support the screen we employ?

* `mainloop()` function
* `pause()` function
* `stop()` function
* None of the above

**Answer:** `mainloop()` function

---

### 4. Which of the following is not correct way to import the tkinter in program?

* `import tkinter as p`
* `import tkinter as t`
* `import tkinter from *`
* All of the above

**Answer:** `import tkinter from *`

---

### 5. GUI stands for?

* Graph User Interaction
* Global User Interaction
* Graphical User Interface
* Graphical User Interaction

**Answer:** Graphical User Interface
