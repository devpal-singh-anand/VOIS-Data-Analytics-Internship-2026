# VOIS Assessment — Linux Permissions Management

## Questions and Answers

### 1. "other" permission is used by

1. Owner
2. Group
3. users other than the file owner
4. None of the above

**Answer:** users other than the file owner

---

### 2. To view the permssions for files and directories, the command is

1. la -l
2. ls -a
3. ls -rw
4. ls -l

**Answer:** ls -l

---

### 3. For the permissions read the command is

1. -w
2. -x
3. -r
4. -rw

**Answer:** -r

---

### 4. How many modes are there in Linux vi editor?

1. 1
2. 3
3. 2
4. 4

**Answer:** 3

---

### 5. A file system assigns

1. Owner and group to each file directory
2. Only owner to each file directory
3. Only group to each file directory
4. username and group to each file directory

**Answer:** Owner and group to each file directory
