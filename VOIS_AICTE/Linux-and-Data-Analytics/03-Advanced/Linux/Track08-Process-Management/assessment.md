# VOIS Assessment — Getting Started with Process Management

## Questions and Answers

### 1. Process information in the current shell can be obtained by using

* `kill`
* `bg`
* `fg`
* `ps`

**Answer:** `ps`

---

### 2. How to run a process in the background?

* `&`
* `*`
* `?`
* `|`

**Answer:** `&`

---

### 3. What are the two ways to create a child process?

* Only through `fork()`
* Only through calling one of the `exec()` functions
* Call `fork()` and call one of the `exec()` functions
* None of the above

**Answer:** Call `fork()` and call one of the `exec()` functions

---

### 4. Which command is used to bring the background process to foreground?

* `bg`
* `fg`
* `background`
* `foreground`

**Answer:** `fg`

---

### 5. Which signal is sent by the command `kill -9`?

* `INT`
* `TERM`
* `KILL`
* `STOP`

**Answer:** `KILL`
