# VOIS Assessment — Getting Started with Linux Networking

## Questions and Answers

### 1. Command to query the current configuration of network is

* `ifconfig`
* `IP`
* `ifquery`
* `Ping`

**Answer:** `ifquery`

---

### 2. Ping stands for

* Packet Input Grade
* Packet Internet Groper
* Packet Internet Group
* ping has no full form

**Answer:** Packet Internet Groper

---

### 3. Which command is used for assigning IP addresses?

* `ifconfig`
* `IP`
* `Traceroute`
* `ping`

**Answer:** `ifconfig`

---

### 4. Command-line tool for querying DNS servers both interactively and passively is

* `netstat`
* `route`
* `nslookup`
* `tracepath`

**Answer:** `nslookup`

---

### 5. The functions of ping and traceroute are combined into one diagnostic tool called

* `Ping`
* `Traceroute`
* `ifconfig`
* `MTR`

**Answer:** `MTR`
