## 4. IBM Bob Modes, Roles and Permissions

### Modes

| Mode | Purpose |
| ---- | ------- |
| Agent | Carries out the work, such as creating files and running code (used in the previous session's data analysis demo) |
| Plan | Produces a plan for the project |
| Ask | Answers questions only |
| Custom / role-based modes | A mode defined by the user, for example a Project Manager |

### Creating a custom mode

1. Click **Create a new mode**.
2. Give it a **name** (for example, Project Manager).
3. Give it a **slug**, a short identifier. The session used the project name, "healthcare analytics doctor visits".
4. Write the **role definition**, describing what the role does in the project. The text used in the session was shared on Telegram.
5. Leave the optional fields empty and click **Save**.

After saving, the modes available were Agent, Plan, Ask and Project Manager (Bob also has a built-in Project Manager mode).

### Permissions and settings

The permissions panel controls what Bob is allowed to do:

* Edit permission and execute permission
* MCP and sub-tasks
* Auto-approve on or off
* Task limits and maximum cost
* Workspace and sandbox options

### Demonstration

Bob was switched to the Project Manager mode and asked to give the project updates for the next five years. It generated:

* A full **five-year strategy roadmap**, year by year
* A **KPI summary**
* A budget estimate and first-year infrastructure needs
* A quarterly roadmap and key success factors

The point was that one tool can act in several roles depending on the mode, and any number of roles can be added to suit a project.

## 5. Using AI Responsibly

* **AI assists, it does not replace.** IBM Bob helps improve your skills. The comparison used was a smartphone, which replaced separate devices without replacing the person using it.
* **The human makes the decision.** AI guides and helps, but the final decision should be taken based on your own experience, and not handed over to the AI.
* **AI creates and automates roles.** It does not take every job, and it cannot be stopped from developing, so the tools have to be learned and adopted.
* **Building with AI is not the same as being a developer.** Understanding what the AI produces is still required.
* **Protect data.** Companies often do not allow sharing their datasets with AI tools, because of ethics and the risk of a data breach.
* **Keep exploring.** Bob and similar tools change regularly, so try different projects and problem statements to understand them better.
* The purpose of these sessions is not only the certificate, but learning how the tools help in your work and career.

## 7. Course 1: Getting Started with Artificial Intelligence

### 7.1 Introduction to Artificial Intelligence

**What is AI?** A system that enables machines to learn, reason and act in ways that resemble human intelligence. **Data is the oxygen of AI**, since there is no AI without data. Everyday examples include Google Maps, Instagram, Spotify (playlist recommendations) and Netflix.

**AI vs Augmented Intelligence**

| | Artificial Intelligence | Augmented Intelligence |
| - | ----------------------- | ---------------------- |
| Focus | The machine performs the task | The machine helps the human perform better |
| Decision | Taken automatically | Taken by the human |
| Example | A system automatically approves or rejects a loan | A system analyzes the applicant and recommends, and the loan officer decides |

**What AI can predict**

* **Human language:** chatbots and natural language processing (ChatGPT, Gemini)
* **Vision recognition:** face recognition, self-driving cars and driver-assistance systems (ADAS), and early recognition of diseases
* **Fraud detection:** spotting unusual transactions. A credit score system was given as a related example

**Three stages of AI**

| Stage | Meaning | Examples |
| ----- | ------- | -------- |
| Narrow AI | Does one specific task | Face recognition, map route recommendation, chatbots, voice assistants (Alexa, Siri), spam detection |
| Broad AI | Works across several tasks within enterprise and business processes. This is the current stage | Weather alerts and recommendations built into business systems |
| General AI | Works without human involvement. Still theoretical | Not yet practical |

**Three eras of computing:** the era of **tabulation** (data arranged in tables), the era of **programming** (writing instructions for each task) and the era of **AI**. Programming has a drawback: every task needs many lines of code and takes time. AI learns patterns from data instead. The term *artificial intelligence* was introduced by John McCarthy and Marvin Minsky at Dartmouth College.

**Types of data**

| Type | Meaning |
| ---- | ------- |
| Structured | Organized in a table format |
| Unstructured | Text paragraphs, images, audio and video. Said to be the majority of the data available |
| Semi-structured | A mix of both, such as metadata (data about data) |

**Machine learning** is used to **predict and learn**. Predictions are never 100% certain.

| Type | How it works | Example |
| ---- | ------------ | ------- |
| Supervised | Learns from **labelled** data | Training on labelled cat, cow and dog images, then recognizing a new dog image |
| Unsupervised | Finds patterns in **unlabelled** data, called clustering | Grouping the same images by features such as ear shape |
| Reinforcement | Learns by **trial and error** with rewards | Robotics |

### 7.2 Large Language Model Basics

* A **language model** lets AI understand human language naturally.
* **Large** refers to the large number of parameters, and **model** refers to the algorithm that stores and processes information step by step.
* The LLM is the **brain of AI tools** such as ChatGPT and Gemini. Without an LLM, these tools cannot answer.
* **Parameters** are the learned values inside a model. A model with a few billion parameters is comparatively small, and one with tens of billions is large.
* A **small language model** is lighter and handles smaller tasks. A **large language model** handles bigger tasks.
* The **Hugging Face** website lists models of both sizes.

### 7.3 Mastering the Art of Prompting

A **prompt** is the input given to an AI tool. The rules for a good prompt:

* Be **clear and specific**
* Use correct **spelling and grammar**
* Keep it **concise**
* Be polite and respectful of the output
* Use the **appropriate format**
* Avoid slang and jargon
* Do not over-complicate the task or make the prompt too broad, such as a very long essay-like paragraph

An example given was asking ChatGPT to plan a vacation, which returned a day-by-day plan.
