## Questions and Answers

### 1. Which of the following statements create a dictionary?

* `d = {}`
* `d = {"john":40, "peter":45}`
* `d = {40:"john", 45:"peter"}`

**Answer:** All of the mentioned

---

### 2. What is the output of the following list operation?

```python
aList = [10, 20, 30, 40, 50, 60, 70, 80]
print(aList[2:5])
print(aList[:4])
print(aList[3:])
```

**Answer:**

```text
[30, 40, 50]
[10, 20, 30, 40]
[40, 50, 60, 70, 80]
```

**Option:** 2

---

### 3. What is the output of the following?

```python
aList = [1, 2, 3, 4, 5, 6, 7]
pow2 = [2 * x for x in aList]
print(pow2)
```

**Answer:**

```text
[2, 4, 6, 8, 10, 12, 14]
```

**Option:** 1

### 4. What will be the output of the following Python code snippet?

```python
d = {"john":40, "peter":45}
d["john"]
```

**Answer:** `40`
