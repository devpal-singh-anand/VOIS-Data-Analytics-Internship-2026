# VOIS & Vodafone Idea Foundation — Data Analytics Internship

> Documentation and learning repository for the **VOIS and Vodafone Idea Foundation Data Analytics Internship Program**, facilitated by **Edunet Foundation**.

## About

This repository contains the learning material and documentation collected throughout the internship.

The internship is a structured **4-week learning journey** focused on developing foundational and practical skills in **Data Analytics**, supported by hands-on learning and technical coursework.

The repository is organized to keep course lectures, assessments, certificates, and live-session material easy to navigate and reference.

## Course Organization

The **Linux and Data Analytics** learning material is organized into three levels:

* **Basic** — 9 courses
* **Intermediate** — 6 courses
* **Advanced** — 7 courses

Each individual course is maintained as a separate directory to keep its material self-contained.

### Course Contents

Completed courses follow a consistent structure:

```text
Course/
├── lecture.md
├── assessment.md
└── certificate.pdf
```

| File              | Purpose                                             |
| ----------------- | --------------------------------------------------- |
| `lectures.md`     | Structured notes and concepts covered in the course |
| `assessment.md`   | Knowledge checks and assessment material            |
| `certificate.pdf` | Certificate received upon course completion         |

## Live Sessions

The `Live/` directory contains resources and documentation related to the internship's live sessions, including orientation, learning sessions, announcements, and other relevant material.
