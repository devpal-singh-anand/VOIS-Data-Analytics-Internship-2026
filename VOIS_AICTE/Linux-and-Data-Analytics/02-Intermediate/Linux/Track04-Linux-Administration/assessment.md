# VOIS Assessment — Linux Administration

## Questions and Answers

### 1. Which command is used to display the OS name?

* uname
* top
* vmstat
* ssh

**Answer:** uname

---

### 2. A directory under a directory is called as?

* Root directory
* Subdirectory
* Home directory
* Parent directory

**Answer:** Subdirectory

---

### 3. Which command is used to check the current target on your system?

* systemctl get-default
* systemctl set-default
* systemctl status
* systemctl target

**Answer:** systemctl get-default

---

### 4. What is used to display and monitor the disk I/O usage details?

* iotop
* htop
* vmstat
* lsof

**Answer:** iotop

---

### 5. Which command is used to update your system?

* sudo apt update
* sudo apt install ssh
* sudo systemctl start ssh
* sudo ufw allow ssh

**Answer:** sudo apt update
