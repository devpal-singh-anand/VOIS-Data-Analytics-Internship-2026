# VOIS Assessment — Basics of Linux Operating System

## Questions and Answers

### 1. Which of the following stages included GRUB boot loader?

* Stage 1 boot loader
* Stage 2 boot loader
* Kernel
* init

**Answer:** Stage 2 boot loader

---

### 2. Which among the following interacts directly with system hardware?

* Shell
* Commands
* Kernel
* Applications

**Answer:** Kernel

---

### 3. When the system is booted, then which of the following is loaded in memory?

* Shell
* Commands
* Kernel
* Applications

**Answer:** Kernel

---

### 4. Which is the core of the operating system?

* Shell
* Kernel
* Command
* Script

**Answer:** Kernel

---

### 5. Which one of the directory does not contain binary files?

* `/bin`
* `/sbin`
* `/etc`
* None of the mentioned

**Answer:** `/etc`
