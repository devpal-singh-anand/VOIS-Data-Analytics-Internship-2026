# VOIS Assessment — Getting Started with Linux File System

## Questions and Answers

### 1. In which of the following directory does the configuration files are present?

* `/bin/`
* `/root/`
* `/etc/`
* `/dev`

**Answer:** `/etc/`

---

### 2. Identify the command which is used to remove files.

* `delete`
* `rm`
* `dm`
* `erase`

**Answer:** `rm`

---

### 3. The `/boot` directory stores the data that is used

* before the kernel begins executing user mode programs
* after the kernel begins executing user mode programs
* before the bootloader is loaded in the RAM
* none of the mentioned

**Answer:** before the kernel begins executing user mode programs

---

### 4. The directory `/opt` is reserved for

* installation of add-on application software packages
* optional booting files
* optional user specific files
* none of the mentioned

**Answer:** installation of add-on application software packages

---

### 5. Which of the following commands is used to display and create files?

* `cat`
* `lyrix`
* `vi`
* `ed`

**Answer:** `cat`
