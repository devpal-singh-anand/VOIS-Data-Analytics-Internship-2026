# System Utility

A **system utility** provides the functionalities of an operating system to the user.

System utilities:

* Help the user access operating-system features.
* Provide useful functionality to the user.
* Can be used for specialized tasks.

# W Command

The `w` command in Linux is used to show:

* Who is currently logged on.
* What the logged-in users are doing.

This command shows information about the users currently on the machine and their processes.
