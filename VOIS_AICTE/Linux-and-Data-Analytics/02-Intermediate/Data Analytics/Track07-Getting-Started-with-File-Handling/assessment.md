# VOIS Assessment — Getting Started with File Handling

## Questions and Answers

### 1. There are basically _______ types of data files

* 1
* 2
* 3
* 4

**Answer:** 2. 2

---

### 2. Regular text files have an extension of _______.

* .txt
* .py
* .pdf
* .csv

**Answer:** 1. .txt

---

### 3. Which command will open a file named "hello.txt" in write mode?

* file = open("hello.txt", w)
* file = open("hello.txt")
* file = open("hello.txt", r)
* None of these

**Answer:** 4. None of these

---

### 4. Which statement will return one line from a file?

* f.readline()
* f.readlines()
* f.read()
* f.line()

**Answer:** 1. f.readline()

---

### 5. which statement will read 5 characters from file (Filename f)?

* f.read()
* f.reads(5)
* f.read(5)
* f.readline()

**Answer:** 3. f.read(5)
