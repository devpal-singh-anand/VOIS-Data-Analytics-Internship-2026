# VOIS Assessment — Linux VI Text Editors

## Questions and Answers

### 1. For navigation purposes, the mode should be ______ mode.

* Command
* Input
* Insert
* Ex

**Answer:** Command

---

### 2. Which of the following mode (s) are used in vi editor?

* Insert mode
* Command mode
* Both of above
* None of above

**Answer:** Both of above

---

### 3. Which command is used to close vi editor?

* q
* wq
* Both q and wq
* None of the mentioned

**Answer:** Both q and wq

---

### 4. Which of the following command is used to "replace the current character" in the vi editor?

* R
* rr
* r
* rc

**Answer:** r

---

### 5. Which vi editor command copies the current line of the file?

* yy
* yw
* yc
* None of the mentioned

**Answer:** yy
