Students who had earlier submitted the project with errors (wrong naming, missing details, inaccessible files, etc.) were given an **extension window to resubmit** so they don't miss their certificates.

## How to Submit the DIY Project

1. Log in to the LMS using your credentials (via the link already shared, or by searching **voisforpe.com**).
2. On the left navigation menu, click **DIY Project**.
3. Select **Data Analytics** from the list of available projects.
4. Choose the assigned project: **Healthcare Analytics for Doctor Visit**.
5. Click **View Course** to access:
   - The reference video (optional, for guidance)
   - The dataset for download
   - The PPT template/reference
   - The submission form
6. Complete your analysis (using the video as a guide if needed, or independently if confident).
7. Submit via the **DIY Project Submission** option (third tab).

---

## PPT Structure Requirements

| Slide | Content |
|---|---|
| 1 | Project name **"Healthcare Analytics for Doctor Visit — TRIRC"**, your full name, and your AICTE ID |
| 2 | Problem statement |
| 3 | About the dataset (columns, data types — text/number/float, etc.) |
| 4 | End users (who benefits from this project) |
| 5 | Technology used (Python, Google Colab, Jupyter Notebook, Pandas, NumPy, etc.) |
| 6 | Results (screenshots of code output, graphs, visualizations — 2–3 recommended) |
| 7 | Thank you slide |

> ⚠️ **Important:** The project name on Slide 1 must exactly match **"Healthcare Analytics for Doctor Visit — TRIRC"**, followed by your name and AICTE ID. This is the most common reason for rejected submissions — double-check it before submitting.

## Submission Channels & Deadline

- Submit on **both**:
  1. The LMS (DIY Project Submission tab)
  2. The **Google Form** (green-colored form titled "TRIRC DIY Project Submission Form")
- If you already submitted correctly on the Google Form, you do **not** need to resubmit there — only fix the LMS submission if needed (naming, file errors, etc.).
- **Resubmission is allowed** on the LMS for anyone whose project was flagged as incorrect/unevaluated.
- **Final deadline: 10 October 2026.**

## GitHub Link

- **Optional**, but strongly recommended.
- Upload your project (dataset, notebook/IPYNB file) to GitHub and add the link in your PPT.
- Helps evaluators verify your work and strengthens your resume/portfolio for future interviews.
