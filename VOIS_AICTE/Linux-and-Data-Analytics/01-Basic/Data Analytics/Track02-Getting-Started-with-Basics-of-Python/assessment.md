# VOIS Assessment — Getting Started with Basics of Python

## Questions and Answers

### 1. Which of the following option is not a core data type in the Python language?

* Dictionary
* Lists
* Class
* All of the above

**Answer:** Class

---

### 2. Which one of the following has the highest precedence in the expression?

* Division
* Subtraction
* Power
* Parentheses

**Answer:** Parentheses

---

### 3. In Python, a variable must be declared before it is assigned a value.

* True
* False

**Answer:** False

---

### 4. Which of the following is not a keyword in Python language?

* `val`
* `raise`
* `try`
* `with`

**Answer:** `val`

---

### 5. Which of the following statements assigns the value 10 to the variable `x` in Python?

* `x << 100`
* `x + 100`
* `x = 100`
* `x := 100`

**Answer:** `x = 100`
