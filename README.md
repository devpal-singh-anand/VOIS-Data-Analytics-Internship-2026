## About

This repository documents my learning and project work completed during the **VOIS and Vodafone Idea Foundation Data Analytics Internship Program**.

The internship is a structured **4-week learning journey** focused on developing foundational and practical skills in **Data Analytics**, supported by technical coursework, live sessions, hands-on exercises, and project-based learning.

The repository brings together:

* Linux and Data Analytics coursework
* Lecture notes, assessments, and course certificates
* Live-session documentation
* Minor project submission
* Major project submission

The goal is to maintain a structured record of the internship journey — from learning the fundamentals to applying data analytics concepts through practical projects.

### Minor Project Submission

The `Minor Project Submission/` directory contains the internship's **minor project** based on the **CarDekho used-vehicle dataset**.

#### Car Market Trends Analysis

The project investigates how factors such as:

* Vehicle age
* Kilometers driven
* Fuel type
* Transmission type
* Ownership history

influence used-vehicle pricing and market trends.

The analysis uses **Exploratory Data Analysis (EDA)** and statistical techniques to identify relationships, patterns, and variations within the used-vehicle market.

| File                                                 | Purpose                                                                 |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| `Devpal's_Car_Market_Trends_Analysis_CarDekho.ipynb` | Jupyter notebook containing the complete analysis and code              |
| `Devpal's_Car_Market_Trends_Analysis_CarDekho.pptx`  | Presentation summarizing the analysis, visualizations, and key findings |

### Major Project Submission

The `Major Project Submission/` directory contains the internship's **major project**:

#### Seasonal Agriculture Performance Analysis

The project analyzes agricultural data to investigate how agricultural performance varies across different seasons.

The analysis focuses on identifying meaningful:

* Seasonal patterns
* Trends
* Relationships
* Variations
* Performance differences

within the available agricultural dataset.

The project applies data analysis and visualization techniques to transform raw agricultural data into clear, evidence-based insights about seasonal agricultural performance.

**Submission deadline:** 20 September 2026

| File                                                        | Purpose                                                                                 |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `Devpal's Seasonal_Agriculture_Performance_Analysis.ipynb`  | Jupyter notebook containing the complete analysis and code                              |
| `Devpal's Seasonal_Agriculture_Performance_Analysis.pptx`   | Presentation containing the methodology, visualizations, key observations, and findings |
