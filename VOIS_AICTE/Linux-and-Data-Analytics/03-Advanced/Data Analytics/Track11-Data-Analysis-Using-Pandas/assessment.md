# VOIS Assessment — Getting Started with Data Analysis Using Pandas

## Questions and Answers

### 1. When data is presented in tabular format, ________ is employed

* NumPy
* Pandas
* Matplotlib
* All of the above

**Answer:** Pandas

---

### 2. Dataframe in pandas is

* 1D Array
* 2D Array
* 3D Array
* None of the above

**Answer:** 2D Array

---

### 3. Which of the following statement is wrong?

* We can create Series from Dictionary in Python
* Keys of dictionary become index of the series
* Order of indexes created from Keys may not be in the same order as typed in dictionary
* All are correct

**Answer:** All are correct

---

### 4. Which of the following is not correct way to import the pandas in program?

* `import pandas as pd`
* `import pandas`
* `import pandas from *`
* All of the above

**Answer:** `import pandas from *`

---

### 5. Which one of the below describes how a dataframe is represented as a numpy array?

* Shape
* `values`
* `dtype`
* Size

**Answer:** `values`
