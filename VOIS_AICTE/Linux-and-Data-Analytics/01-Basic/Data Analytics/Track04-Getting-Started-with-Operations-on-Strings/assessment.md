### 1. What will the following Python code return?

```python
str1 = "Stack of books"
print(len(str1))
```

**Answer:** `14`

**Option:** 2

### 2. What is printed by the following statements?

```python
s = "python rocks"
print(s[3])
```

The characters are indexed starting from `0`:

```text
p → 0
y → 1
t → 2
h → 3
```

**Answer:** `h`

**Option:** 2

---

### 3. What will be the output of the below Python code?

```python
str1 = "Information"
print(str1[2:8])
```

`str1[2:8]` returns characters from index `2` up to, but not including, index `8`.

**Answer:** `format`

**Option:** 1

---

### 4. What is printed by the following statements?

```python
animal = "dog"
print("animal" + animal)
```

The string `"animal"` is literal text, while `animal` contains `"dog"`.

**Answer:** `animaldog`

**Option:** 4

---

### 5. What will be the output of the above Python code?

```python
str1 = "6/4"
print("str1")
```

Because `"str1"` is inside quotation marks, Python prints the literal string rather than the value stored in `str1`.

**Answer:** `str1`

**Option:** 4
